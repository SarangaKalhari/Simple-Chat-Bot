# Simple Chatbot

A basic chatbot application built with Java and JavaFX. This simple yet functional chatbot can respond to user inputs with predefined responses, demonstrating fundamental concepts of natural language processing and GUI development.

## 📋 Project Overview

This Simple Chatbot is a desktop application that simulates a conversation with users. It uses pattern matching to identify user intents and provides appropriate responses. The application features a clean chat interface built with JavaFX.

## ✨ Features

- Interactive Chat Interface - User-friendly messaging layout

- Basic Pattern Matching - Responds to keywords and phrases

- Multiple Conversation Topics - Greetings, farewells, basic questions

- Clean UI Design - Chat bubbles for messages

- Simple Response System - Predefined responses for common inputs

## 🛠️ Technologies Used

- Java - Core programming language
- HTML
- JavaScript
- CSS - Interface styling

## 💬 How It Works

- The chatbot uses simple pattern matching:

- User types a message

- Bot analyzes keywords in the message

- Bot selects appropriate response from predefined list

- Conversation appears in chat bubbles
